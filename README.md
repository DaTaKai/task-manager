# Тапсырмалар менеджері

React + Vite негізіндегі модульдік task manager.

## Іске қосу

```bash
npm install
npm run dev
```

## Құрылым

- `src/useTasks.js` — күй, localStorage, серверлік сұрауларды имитациялау (оптимистік жаңарту + қате кезінде кері қайтару)
- `src/TaskForm.jsx` — жаңа тапсырма қосу формасы
- `src/TaskFilters.jsx` — іздеу, сүзу, сұрыптау
- `src/TaskItem.jsx` — тапсырма карточкасы (өңдеу, статус, өшіру)
- `src/TaskList.jsx` — тізім
- `src/Toast.jsx` — қате хабарламалары
- `src/App.jsx` — басты логика
- `src/index.css` — стильдер
